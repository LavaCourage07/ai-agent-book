# 《深入理解 AI Agent》小黑插图计划 v2：核心讲解序列 + 强设计补充图

> 本文件取代 `xiaohei-illustration-plan.md` 的正式生产地位。旧方案及两张试作不进入书稿正文。

## 目标与生产规则

每章的小黑图是一套可独立阅读的“视觉课件”，不是点缀。读者顺着图序应能复述：**问题是什么 → 原理是什么 → 如何做 → 如何判断 → 常见错误 → 如何修复或进入下一章**。

每个细分小节至少由一张 **核心解读图（C）** 覆盖；每章额外配置 **强设计补充图（S）**，负责反直觉结论、典型失败、章节转折或整章收束。SVG 保留用于精确结构、公式、协议与数据；小黑图解释因果、判断和行动。

- 预计：**145 张核心解读图 + 42 张强设计补充图 = 187 张**。
- 每张单独生成、单独审核；16:9 纯白底、黑色手绘小黑、少量红橙蓝标注、大片留白。
- 核心图可含极少量必要关系线，但不得做成 PPT/正式流程图；补充图必须采用新的物理隐喻，不能重复核心图。
- 图像编号按章节连续；每张以标题锚点插入，文件放入 `assets/ai-agent-book-illustrations-v2/chNN/`，通过审核后才复制到 `book/images/xiaohei/` 并写入 Markdown。
- **章节交付顺序不可交错**：先完成并嵌入本章全部 C 图，再完成并嵌入本章全部 S 图；逐项核对图数、正文位置、链接、白底和格式后，才可进入下一章。提前产出的 S 图可以保留，但不视为本章完成，且不得替代遗漏的 C 图。

## 分批生产与验收

1. **先生产每章前两张核心图（20 张）**，验证全书视觉语言是否真的能独立讲出“问题→机制”。
2. 之后按章节完整生产：核心图先于补充图；每个章节完成后做一次“只看图复述章节”的覆盖验收。
3. 强设计图只在核心图已覆盖对应知识后生成；它不能代替任何细分概念的教学图。
4. 每张图审核四件事：概念是否正确；因果/判断是否清楚；小黑是否承担动作；是否与相邻 SVG 互补而非重复。
5. 通过后才插入 Markdown；图片 alt 文本要说明图在解释什么，而不是只写“小黑插图”。
